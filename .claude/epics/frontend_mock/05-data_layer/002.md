# Task: Mock data generators (Faker.js + custom)

## Description
Create comprehensive mock data generators using Faker.js and custom logic to produce realistic trading data. This includes generating 50+ instruments (stocks, crypto, forex), realistic candlestick/OHLCV data, 1000+ trade history records, positions, and opportunities with proper statistical distributions.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Technical Details

### Implementation Approach
1. Install Faker.js:
   ```bash
   npm install @faker-js/faker --save-dev
   ```
2. Create type definitions:
   - `/src/types/trading.ts` - Instrument, Candlestick, Trade, Position, Opportunity
3. Create generators:
   - `/src/mocks/generators/instruments.ts` - Generate stock/crypto/forex instruments
   - `/src/mocks/generators/candlesticks.ts` - Generate OHLCV data with volatility
   - `/src/mocks/generators/trades.ts` - Generate trade history with P&L
   - `/src/mocks/generators/positions.ts` - Generate open positions
   - `/src/mocks/generators/opportunities.ts` - Generate trading opportunities
   - `/src/mocks/generators/seed.ts` - Seeded random number generator
4. Implement realistic data patterns:
   - Price movements follow random walk with drift
   - Volume follows log-normal distribution
   - Trade outcomes have realistic win/loss ratio
   - Opportunities include multiple detection strategies
