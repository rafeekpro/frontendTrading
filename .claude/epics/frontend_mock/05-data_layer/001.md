# Task: Mock Service Worker (MSW) setup

## Description
Set up Mock Service Worker (MSW) in browser mode to intercept and mock all API requests for the trading platform frontend. This includes creating a structured handler organization for instruments, trades, authentication, and configuring MSW worker initialization for development-only usage.

## Technical Details

### Implementation Approach
1. Install MSW browser package:
   ```bash
   npm install msw@latest --save-dev
   ```
2. Generate service worker script:
   ```bash
   npx msw init public/ --save
   ```
3. Create handler organization:
   - `/src/mocks/handlers/instruments.ts` - GET /api/instruments, GET /api/instruments/:id
   - `/src/mocks/handlers/trades.ts` - POST /api/trades, GET /api/trades
   - `/src/mocks/handlers/auth.ts` - POST /api/auth/login, POST /api/auth/logout
   - `/src/mocks/handlers/index.ts` - Exports all handlers
4. Configure MSW worker initialization:
   - `/src/mocks/browser.ts` - Browser worker setup
   - `/src/main.tsx` - Conditional MSW start (development only)
5. Add environment check to prevent MSW in production
