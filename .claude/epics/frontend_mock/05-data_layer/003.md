# Task: Zustand stores (watchlist, paper trading, AI config)

## Description
Create Zustand stores for client-side state management including watchlist with localStorage persistence, paper trading store for managing balance/positions/trades, and AI configuration store. Includes comprehensive testing utilities for store validation and state persistence.

## Technical Details

### Implementation Approach
1. Install Zustand:
   ```bash
   npm install zustand
   ```
2. Create store type definitions:
   - `/src/types/stores.ts` - WatchlistStore, TradingStore, AIConfigStore
3. Create stores:
   - `/src/stores/watchlist.ts` - Watchlist with localStorage persistence
   - `/src/stores/paperTrading.ts` - Paper trading balance, positions, trades
   - `/src/stores/aiConfig.ts` - AI provider settings
4. Implement localStorage middleware:
   - Watchlist persists to `trading-watchlist` key
   - Paper trading persists to `paper-trading-state` key
   - AI config persists to `ai-config` key
5. Create testing utilities:
   - `/src/stores/__tests__/utils.ts` - Store test helpers
   - Store tests verify actions, persistence, and state updates
