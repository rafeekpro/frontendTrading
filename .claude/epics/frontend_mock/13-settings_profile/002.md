# Task: Profile settings component

## Description
Build user profile settings form with avatar upload, name, email, timezone, and language preferences. Include form validation with Zod schema and optimistic updates. Display mock user data with ability to edit and save changes (persisted to localStorage).

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria

- [ ] Mock user data generator in `/src/lib/mock-data/user-profile.ts`
- [ ] Avatar upload (mock - file picker but no actual upload)

## Technical Details

### Implementation Approach
1. Create mock user data in `src/lib/mock-data/user-profile.ts`
2. Create `src/pages/Settings/tabs/ProfileSettingsTab.tsx`
3. Use React Hook Form + Zod for form management:
   - `src/lib/validations/profile-schema.ts` (Zod schema)
4. Avatar component: `src/components/settings/AvatarUpload.tsx`
5. Save to localStorage: `src/lib/utils/settings-storage.ts`
6. Use TanStack Query mutation for save action
7. Toast notifications with shadcn/ui Toast component
