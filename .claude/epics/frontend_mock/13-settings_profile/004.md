# Task: Notification settings

## Description
Build notification preferences panel with toggles for different notification types (email, push, trade alerts, opportunity alerts, system alerts, weekly reports). Include notification channel preferences and frequency settings. Changes persist to localStorage.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] NotificationSettingsTab component at `/src/pages/Settings/tabs/NotificationSettingsTab.tsx`
- [ ] Mock notification settings data
- [ ] Toggle switches for: Email notifications, Push notifications, Trade alerts, Opportunity alerts, System alerts, Weekly performance report
- [ ] Email frequency selector (real-time, hourly, daily)
- [ ] Quiet hours settings (time range picker)
- [ ] Alert thresholds (e.g., notify when P&L > $X)
- [ ] Test notification button (shows toast)
- [ ] "Save Changes" and "Reset to Defaults" buttons
- [ ] Changes persist to localStorage
- [ ] Success toast after save
- [ ] Tests cover all toggles and settings
- [ ] Accessibility compliant (switch labels, descriptions)

## Technical Details

### Implementation Approach
1. Create mock notification settings in `src/lib/mock-data/notification-settings.ts`
2. Create `src/pages/Settings/tabs/NotificationSettingsTab.tsx`
3. Create reusable components:
   - `src/components/settings/NotificationToggle.tsx`
   - `src/components/settings/QuietHoursSelector.tsx`
   - `src/components/settings/ThresholdInput.tsx`
4. Use shadcn/ui Switch component for toggles
5. Use Zod schema for validation: `src/lib/validations/notification-schema.ts`
6. Persist to localStorage: reuse `settings-storage.ts`
7. Test notification shows toast with mock message
