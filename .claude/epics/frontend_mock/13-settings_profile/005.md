# Task: Theme switcher implementation

## Description
Implement dark/light theme switcher with system preference detection. Create ThemeProvider context to manage theme state across the application. Apply theme classes to root element and persist preference to localStorage. Ensure all components support both themes with proper color contrast.

## Technical Details

### Implementation Approach
1. Create `src/lib/providers/ThemeProvider.tsx` with Context API
2. Create `src/hooks/use-theme.ts` custom hook
3. Update `tailwind.config.js` to enable dark mode class strategy
4. Create theme colors in Tailwind config or CSS variables
5. Add theme toggle button: `src/components/layout/ThemeToggle.tsx`
6. Update DisplaySettingsTab with theme selector
7. Apply `dark` class to `<html>` element based on theme
8. Use localStorage key: 'theme-preference'
9. SSR-safe theme initialization (read from localStorage before render)
10. Update all components to use dark: variants
