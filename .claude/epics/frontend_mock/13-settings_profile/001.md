# Task: Settings page layout

## Description
Create the main settings page with tab navigation for different settings categories (Profile, API Connections, Notifications, Display). Implement responsive layout with sidebar navigation on desktop and tab bar on mobile. This is the foundation for all settings features.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] SettingsPage component at `/src/pages/Settings/SettingsPage.tsx`
- [ ] TypeScript types for settings structures in `/src/types/settings.ts`
- [ ] Tab navigation with routes: /settings/profile, /settings/api, /settings/notifications, /settings/display
- [ ] Sidebar navigation on desktop (left side)
- [ ] Tab bar navigation on mobile (top)
- [ ] Active tab highlighting
- [ ] Breadcrumb navigation
- [ ] Settings icon in main navigation
- [ ] Responsive layout (desktop, tablet, mobile)
- [ ] Loading states for tab content
- [ ] Tests cover navigation and routing
- [ ] Accessibility compliant (keyboard navigation, ARIA)

## Technical Details

### Implementation Approach
1. Create TypeScript types in `src/types/settings.ts`
2. Create `src/pages/Settings/SettingsPage.tsx` with tab layout
3. Create `src/components/settings/SettingsSidebar.tsx` (desktop)
4. Create `src/components/settings/SettingsTabBar.tsx` (mobile)
5. Use React Router nested routes for tabs
6. Route structure:
   ```
   /settings
     /settings/profile (default)
     /settings/api
     /settings/notifications
     /settings/display
   ```
7. Shared layout component: `src/components/settings/SettingsLayout.tsx`
