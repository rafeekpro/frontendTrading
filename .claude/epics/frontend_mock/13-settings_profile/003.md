# Task: API connections UI

## Description
Build API connections management interface showing broker and exchange connections. Display connection status, last sync time, and masked API keys. Include "Add Connection" and "Test Connection" buttons (mock actions with loading states). This is UI-only with no real integration.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] APIConnectionsTab component at `/src/pages/Settings/tabs/APIConnectionsTab.tsx`
- [ ] Mock API connections data (Alpaca, Interactive Brokers, Binance)
- [ ] Connection cards showing: Provider logo, Status badge, Masked API key, Last sync time
- [ ] Status indicators: Connected (green), Disconnected (gray), Error (red)
- [ ] "Add Connection" button opens provider selection modal
- [ ] "Test Connection" button with loading state (mock 2s delay)

- [ ] "Edit" button to update API keys (form with masked inputs)
- [ ] Connection instructions panel (collapsible)
- [ ] Empty state when no connections
- [ ] Tests cover all actions and states
- [ ] Accessibility compliant
