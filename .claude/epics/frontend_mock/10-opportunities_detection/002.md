# Task: Opportunities list page

## Description
Build the main opportunities list page with grid/list view toggle, filtering, sorting, and infinite scroll. Display opportunity cards with key metrics including confidence score, potential return, risk level, and detection criteria. Integrate with TanStack Query for data fetching and Zustand for UI state management.

1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.
