# Task: Mock data generators for opportunities

## Description
Create comprehensive mock data generators for trading opportunities including detection criteria, AI analysis, price targets, and risk metrics. Generate at least 50 realistic opportunities with varying confidence levels, risk profiles, and statuses. This provides the foundation for realistic opportunities detection demos.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] TypeScript types defined for Opportunity interface
- [ ] Mock generator creates 50+ opportunities with realistic data
- [ ] Detection criteria include common technical patterns (RSI, MACD, breakout, etc.)
- [ ] AI analysis text is realistic and varies by provider (OpenAI/Claude/Gemini)
- [ ] Price targets and stop losses are mathematically consistent
- [ ] Confidence scores distributed realistically (bell curve, 40-90)
- [ ] Risk levels correlate with opportunity parameters
- [ ] Status distribution: 70% active, 20% triggered, 10% expired
- [ ] Opportunities span multiple instruments from mock data
- [ ] Timestamps realistic (within last 7 days)
- [ ] Tests validate data structure and constraints
- [ ] Seed script initializes opportunities data

## Technical Details

### Implementation Approach
1. Create `src/types/opportunity.ts` with Opportunity interface
2. Create `src/lib/mock-data/opportunities.ts` with generator
3. Detection criteria patterns:
   - RSI oversold/overbought
   - MACD crossover
   - Moving average breakout
   - Volume spike
   - Support/resistance levels
   - Pattern recognition (head & shoulders, double bottom, etc.)
4. AI analysis templates by provider:
   - OpenAI: Quantitative focus
   - Claude: Risk analysis focus
   - Gemini: Technical pattern focus
5. Price targets calculated with realistic risk/reward ratios (1:2 to 1:3)
6. Create seed script in `src/lib/mock-data/seed-opportunities.ts`
