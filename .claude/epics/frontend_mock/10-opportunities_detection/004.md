# Task: MSW handlers for opportunities API

## Description
Create Mock Service Worker (MSW) handlers for opportunities API endpoints including list, detail, filters, and actions (dismiss, trigger). Support pagination, filtering, sorting, and realistic response delays. This provides the backend simulation for opportunities detection features.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] MSW handlers created in `/src/mocks/handlers/opportunities.ts`
- [ ] GET /api/opportunities - list with pagination, filtering, sorting
- [ ] GET /api/opportunities/:id - single opportunity detail
- [ ] POST /api/opportunities/:id/dismiss - mark opportunity as dismissed
- [ ] POST /api/opportunities/:id/trigger - mark opportunity as triggered
- [ ] GET /api/opportunities/stats - summary statistics (active count, avg confidence, etc.)
- [ ] Query parameters support: page, limit, type, riskLevel, minConfidence, maxConfidence, status, sortBy, sortOrder
- [ ] Realistic response delays (100-300ms)
- [ ] Error scenarios: 404 for invalid ID, 500 for server errors (10% random chance for testing)
- [ ] Response includes total count for pagination
- [ ] Filtering logic matches frontend expectations
- [ ] Tests validate all endpoints and scenarios
- [ ] Handlers registered in MSW browser setup

## Technical Details

### Implementation Approach
1. Create `src/mocks/handlers/opportunities.ts` with all endpoints
2. Import mock opportunities data from Task 001
3. Implement filtering logic:
   - Type filter: 'long' | 'short'
   - Risk level filter: 'low' | 'medium' | 'high'
   - Confidence range: minConfidence to maxConfidence
   - Status filter: 'active' | 'triggered' | 'expired'
4. Implement sorting:
   - By date (newest/oldest)
   - By confidence (high/low)
   - By potential return (high/low)
5. Pagination with limit/offset
6. Statistics endpoint calculates from mock data
7. Add realistic delays with `http.delay()`
8. Register handlers in `src/mocks/browser.ts`
