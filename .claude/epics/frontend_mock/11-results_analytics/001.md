# Task: Results dashboard page

## Description
Create the main results dashboard page with performance overview, key metrics cards (total P&L, win rate, profit factor, etc.), and quick access to detailed analytics. Display summary charts and recent trades. This is the landing page for traders to monitor their overall performance.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] ResultsDashboardPage component at `/src/pages/Results/ResultsDashboardPage.tsx`
- [ ] Mock data generators for trading results (1000+ trades)
- [ ] TypeScript types for TradingResult and PerformanceMetrics
- [ ] Key metrics cards: Total P&L, Win Rate, Total Trades, Profit Factor, Sharpe Ratio, Max Drawdown
- [ ] Summary P&L chart (last 30 days line chart)
- [ ] Win/Loss distribution pie chart
- [ ] Top performers and worst performers lists
- [ ] Recent trades list (last 10 trades)
- [ ] Date range selector in header
- [ ] Loading states with skeleton cards
- [ ] Responsive layout (desktop, tablet, mobile)
- [ ] Color coding (green for profit, red for loss)
- [ ] Tests cover all metrics calculations and display
- [ ] Accessibility compliant

## Technical Details

### Implementation Approach
1. Create TypeScript types in `src/types/trading-result.ts`
2. Mock data generator in `src/lib/mock-data/trading-results.ts`:
   - Generate 1000+ trades with realistic P&L distribution
   - 55% win rate (realistic for good trader)
   - Profit factor > 1.5
   - Varying holding periods
3. Create `src/pages/Results/ResultsDashboardPage.tsx`
4. Create metrics cards: `src/components/results/MetricsCard.tsx`
5. Create charts components:
   - `src/components/results/PLSummaryChart.tsx` (Recharts line chart)
   - `src/components/results/WinLossChart.tsx` (Recharts pie chart)
6. Create `src/hooks/use-trading-results.ts` with TanStack Query
7. Utility functions for metrics calculations in `src/lib/utils/metrics.ts`
