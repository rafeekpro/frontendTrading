# Task: MSW handlers for results API

## Description
Create Mock Service Worker (MSW) handlers for results and analytics API endpoints including trade history, performance metrics, and filtered queries. Support pagination, date range filtering, and aggregations. This provides the backend simulation for results features.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] MSW handlers created in `/src/mocks/handlers/results.ts`
- [ ] GET /api/results/trades - list with pagination, filtering, sorting
- [ ] GET /api/results/trades/:id - single trade detail
- [ ] GET /api/results/metrics - performance metrics (overall or date range)
- [ ] GET /api/results/daily-pl - daily P&L aggregation
- [ ] GET /api/results/monthly-pl - monthly P&L aggregation
- [ ] GET /api/results/instrument-allocation - trading activity by instrument
- [ ] GET /api/results/drawdown - drawdown calculation over time
- [ ] Query parameters: startDate, endDate, instrumentId, side, minPL, maxPL, strategy, page, limit, sortBy, sortOrder
- [ ] Realistic response delays (100-300ms)
- [ ] Error scenarios: 400 for invalid date range, 500 for server errors
- [ ] Response includes pagination metadata
- [ ] Aggregation endpoints return correct calculations
- [ ] Tests validate all endpoints and edge cases
- [ ] Handlers registered in MSW browser setup

## Technical Details

### Implementation Approach
1. Create `src/mocks/handlers/results.ts` with all endpoints
2. Import mock trading results from Task 001
3. Implement filtering logic:
   - Date range filter (startDate to endDate)
   - Instrument filter
   - Side filter (long/short)
   - P&L range filter
   - Strategy filter
4. Implement sorting (by date, P&L, instrument, etc.)
5. Aggregation calculations:
   - Daily P&L: Sum trades by date
   - Monthly P&L: Sum trades by month
   - Instrument allocation: Group by instrument, sum volume
   - Drawdown: Calculate cumulative P&L and track maximum decline
6. Metrics calculation:
   - Win rate, profit factor, Sharpe ratio, max drawdown
7. Pagination with limit/offset
8. Register handlers in `src/mocks/browser.ts`
