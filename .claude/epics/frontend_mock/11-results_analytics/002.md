# Task: Performance charts components

## Description
Build comprehensive performance visualization components including cumulative P&L line chart, monthly returns bar chart, portfolio allocation pie chart, win/loss distribution, and drawdown chart. All charts must be interactive, responsive, and performant with large datasets.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] CumulativePLChart component (line chart showing cumulative profit over time)
- [ ] MonthlyReturnsChart component (bar chart showing monthly P&L)
- [ ] WinLossDistributionChart component (histogram showing profit/loss distribution)
- [ ] DrawdownChart component (area chart showing drawdown over time)
- [ ] InstrumentAllocationChart component (pie/donut chart of trading activity by instrument)
- [ ] All charts interactive (tooltips, zoom, pan where appropriate)
- [ ] Responsive design (adjusts to container width)
- [ ] Loading states with skeletons
- [ ] Empty state when no data
- [ ] Export chart as PNG/SVG functionality
- [ ] Legend with click-to-hide series
- [ ] Customizable date range (passed as prop)
- [ ] Tests for data transformation and rendering
- [ ] Performance optimized (renders 1000+ data points smoothly)

## Technical Details

### Implementation Approach
1. Create base chart wrapper: `src/components/results/charts/BaseChart.tsx`
2. Individual chart components:
   - `src/components/results/charts/CumulativePLChart.tsx`

   - `src/components/results/charts/WinLossDistributionChart.tsx`

   - `src/components/results/charts/InstrumentAllocationChart.tsx`
3. Data transformation utilities:
   - `src/lib/utils/chart-data-transforms.ts`
   - Calculate cumulative P&L
   - Aggregate by month
   - Calculate drawdown
   - Bucket win/loss distribution
4. Export functionality with html2canvas or similar
5. Shared tooltip component with formatted values
