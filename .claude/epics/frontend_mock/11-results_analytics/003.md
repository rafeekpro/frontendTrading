# Task: Trade history table with export

## Description
Build comprehensive trade history table with sorting, filtering, pagination, and export functionality. Display all trade details including instrument, entry/exit prices, P&L, holding period, and strategy. Support CSV and JSON export with filtered data.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] TradeHistoryTable component at `/src/components/results/TradeHistoryTable.tsx`
- [ ] Columns: Date, Time, Instrument, Side (Long/Short), Entry Price, Exit Price, Quantity, P&L ($), P&L (%), Commission, Net P&L, Holding Period, Strategy
- [ ] Sortable by all columns (ascending/descending)
- [ ] Filterable by: Date range, Instrument, Side, Profit/Loss, Strategy
- [ ] Pagination with configurable page size (10, 25, 50, 100 rows)
- [ ] Row selection (multi-select with checkboxes)
- [ ] Export selected or all rows to CSV
- [ ] Export selected or all rows to JSON
- [ ] Copy to clipboard functionality
- [ ] Color coding for P&L (green positive, red negative)
- [ ] Click row to view trade details (modal or expansion)
- [ ] Loading state with skeleton rows
- [ ] Empty state when no trades match filters
- [ ] Responsive design (horizontal scroll on mobile)
- [ ] Tests cover sorting, filtering, pagination, export
- [ ] Virtualization for large datasets (1000+ rows)

## Technical Details

### Implementation Approach
1. Choose table library: TanStack Table (recommended) or custom table
2. Create `src/components/results/TradeHistoryTable.tsx` with TanStack Table
3. Create filter panel: `src/components/results/TradeHistoryFilters.tsx`
4. Export utilities:
   - `src/lib/utils/export-csv.ts` (convert to CSV)
   - `src/lib/utils/export-json.ts` (convert to JSON)
5. Use `react-virtual` for virtualization if needed
6. Zustand store for table state: `src/lib/stores/trade-history-store.ts`
7. Trade detail modal: `src/components/results/TradeDetailModal.tsx`
