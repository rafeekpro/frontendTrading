# Task: Base layout components (Sidebar, Header, Footer)

## Description
Create foundational layout components for the trading platform including a collapsible Sidebar with navigation, Header with branding and theme toggle placeholder, and Footer component. Implement a responsive layout that adapts to mobile, tablet, and desktop viewports with proper accessibility features and keyboard navigation support.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Technical Details

### Implementation Approach
1. Create Sidebar component:
   - Use shadcn/ui Sheet for mobile drawer
   - NavigationMenu for desktop
   - State management for collapse/expand
   - Active link detection with react-router
2. Create Header component:
   - Flexbox layout for alignment
   - Hamburger button for mobile (triggers Sidebar)
   - Profile dropdown using shadcn/ui DropdownMenu
   - Theme toggle placeholder (Button component)
3. Create Footer component:
   - Flexbox with responsive wrapping
   - Links using react-router Link component
   - Environment variable for version number
4. Create Layout container:
   - Composition pattern for children
   - CSS Grid for layout structure
   - Responsive breakpoints (mobile: <768px, tablet: 768-1024px, desktop: >1024px)
5. Testing approach:
   - Component unit tests with React Testing Library
   - Accessibility tests with jest-axe
   - Responsive behavior tests with viewport resizing
   - Navigation interaction tests
