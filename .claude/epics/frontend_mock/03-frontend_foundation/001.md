## Technical Details

### Implementation Approach
1. Install TailwindCSS and dependencies:
   - `npm install -D tailwindcss postcss autoprefixer`
   - Initialize with `npx tailwindcss init -p`
2. Configure Tailwind for React:
   - Set up content paths in tailwind.config.js
   - Configure theme extensions (colors, fonts)
   - Enable dark mode with class strategy
3. Initialize shadcn/ui:
   - Run `npx shadcn-ui@latest init`
   - Configure components.json with alias and style preferences
   - Install initial components (Button, Card)
4. Create base theme:
   - Define CSS variables for light/dark themes
   - Set up color palette (green for gains, red for losses)
   - Configure typography scale
5. Test setup:
   - Create sample page with themed components
   - Verify dark mode toggle functionality
   - Test responsive breakpoints
