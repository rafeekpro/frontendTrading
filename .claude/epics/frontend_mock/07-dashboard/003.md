# Task: Instrument detail page with TradingView charts

## Description
Create a comprehensive instrument detail page featuring professional-grade TradingView Lightweight Charts for candlestick visualization. Display real-time market data with multiple timeframe options (1m, 5m, 1h, 1d). Include OrderBook component showing bid/ask depth and MarketStats panel with volume, high/low, and other key metrics. This page provides traders with all information needed for analysis.

## Technical Details

### Implementation Approach
1. Install TradingView Lightweight Charts: `lightweight-charts`
2. Create CandlestickChart component:
   - Initialize chart with dark theme
   - Add candlestick series
   - Add volume series (histogram)
   - Handle responsive resizing
   - Expose methods for data updates
3. Create InstrumentDetail page:
   - Fetch instrument data and historical OHLCV
   - Implement timeframe state management
   - Grid layout: Chart (main area), OrderBook (sidebar), MarketStats (top)
4. Create OrderBook component:
   - Display bids (green) and asks (red)
   - Depth bars showing cumulative volume
   - Highlight best bid/ask spread
5. Create MarketStats component:
   - Key metrics in card layout
   - Auto-update from market data hook
6. Handle real-time updates:
   - Subscribe to price updates via useMarketData
   - Update chart with new candles
   - Throttle updates to avoid performance issues
