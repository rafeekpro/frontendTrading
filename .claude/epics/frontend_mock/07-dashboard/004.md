# Task: Instruments list and watchlist management

## Description
Create a comprehensive InstrumentsList page with advanced search, filtering, and sorting capabilities. Implement a Watchlist page that displays user-favorited instruments with drag-and-drop reordering. Integrate with Zustand store for watchlist persistence. This provides traders with powerful tools to organize and monitor their preferred instruments.

## Technical Details

### Implementation Approach
1. Create InstrumentsList page:
   - Fetch all instruments via useInstruments hook
   - Implement search/filter/sort logic in React state
   - Use virtualization library (@tanstack/react-virtual) for performance
   - Render InstrumentRow components
2. Create InstrumentRow component:
   - Display instrument data in table row format
   - Star icon toggles watchlist (calls Zustand store action)
   - Click handler navigates to detail page
   - Highlight row on hover
3. Create Zustand watchlist store:
   - State: `watchlist: string[]` (instrument IDs)
   - Actions: addToWatchlist, removeFromWatchlist, reorderWatchlist
   - Persist to localStorage using zustand/middleware
4. Create Watchlist page:
   - Fetch watchlist IDs from Zustand store
   - Fetch full instrument data for watchlist items
   - Implement drag-and-drop using dnd-kit
   - Update Zustand store on reorder
5. Add search/filter/sort controls:
   - SearchBar component with debounce
   - FilterDropdown with multi-select
   - SortButtons for column headers
   - Update URL query params for shareable state
