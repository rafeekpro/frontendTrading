# Task: TanStack Query setup and hooks

## Description
Set up TanStack Query (React Query) for efficient data fetching, caching, and state management. Create a query client configuration with sensible defaults for the trading application, and implement custom hooks for fetching instruments and trades data. This provides the foundation for real-time data updates and optimistic UI patterns throughout the dashboard.

## Acceptance Criteria

## Technical Details

### Implementation Approach
1. Install TanStack Query dependency
2. Create `src/lib/query-client.ts` with QueryClient configuration:
   - Default staleTime: 30 seconds (trading data is time-sensitive)
   - Retry failed requests: 3 attempts with exponential backoff
   - RefetchOnWindowFocus: true (stay synced when user returns)
3. Create `src/hooks/use-instruments.ts` with `useInstruments()` hook
4. Create `src/hooks/use-instrument.ts` with `useInstrument(id)` hook
5. Create `src/hooks/use-trades.ts` with `useTrades(instrumentId)` hook
6. Create `src/hooks/use-market-data.ts` with `useMarketData(instrumentId)` hook
7. Integrate QueryClientProvider in App.tsx
8. Add ReactQueryDevtools component (dev only)
