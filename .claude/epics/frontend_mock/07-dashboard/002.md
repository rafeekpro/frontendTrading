# Task: Dashboard page with instrument cards

## Description
Create the main Dashboard page featuring Squaber-style instrument cards that display real-time trading data. Implement QuickStats cards showing P&L, open positions, and alerts. Add search and filtering capabilities to help users quickly find instruments. This is the primary landing page users see after authentication.

**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] Dashboard page component created at `/src/pages/Dashboard.tsx`
- [ ] InstrumentCard component displays: symbol, name, current price, 24h change %, chart sparkline
- [ ] Cards use Squaber-inspired design (dark theme, glassmorphism, subtle animations)
- [ ] QuickStats section shows: Total P&L, Open Positions count, Active Alerts count

- [ ] Filter dropdown: All, Favorites, Forex, Crypto, Stocks

## Technical Details

### Implementation Approach
1. Create Dashboard page component with layout structure
2. Build InstrumentCard component:
   - Display instrument data (symbol, price, change)
   - Mini sparkline chart using Recharts or TradingView lightweight
   - Hover effects and click handler
   - Favorite star icon (toggle watchlist)
3. Build QuickStats component:
   - Fetch aggregated stats from API or compute from instruments
   - Display in card grid at top of dashboard
   - Icons from lucide-react
4. Implement search and filter logic:
   - useDebounce hook for search (300ms delay)
   - Filter state in URL query params (shareable links)
   - Combine filters with AND logic
5. Add skeleton loading states
6. Style with Tailwind CSS (dark theme, Squaber aesthetics)
