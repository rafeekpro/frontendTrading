# Task: Mock data for hypotheses and backtests

## Description
Create comprehensive mock data generators for research hypotheses, backtest results, and feature definitions. Generate at least 20 hypotheses with varying statuses, realistic backtest performance metrics, and diverse feature engineering examples. This provides the foundation for research framework demos.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] TypeScript types defined for Hypothesis, BacktestResult, and Feature
- [ ] Mock generator creates 20+ hypotheses with realistic names/descriptions
- [ ] Status distribution: 30% draft, 40% testing, 20% validated, 10% rejected
- [ ] Backtest results include equity curves (daily data for 1 year)
- [ ] Performance metrics realistic (win rate 45-65%, profit factor 1.0-2.5)
- [ ] Feature definitions include technical indicators (RSI, MACD, etc.)
- [ ] Formula examples realistic (e.g., "RSI(14) < 30 AND MACD > Signal")
- [ ] Hypothesis parameters include lookback periods, thresholds, etc.
- [ ] Timestamps realistic (created/updated within last 6 months)
- [ ] Tests validate data structure and constraints
- [ ] Seed script initializes research data

## Technical Details

### Implementation Approach
1. Create `src/types/research.ts` with Hypothesis, BacktestResult, Feature interfaces
2. Create `src/lib/mock-data/hypotheses.ts` with generator
3. Hypothesis name templates:
   - "RSI Oversold Reversal Strategy"
   - "MACD Crossover with Volume Confirmation"
   - "Mean Reversion in Volatile Markets"
   - "Momentum Breakout with Support/Resistance"
4. Feature types:
   - Technical: RSI, MACD, MA, Bollinger Bands, ATR, Volume
   - Fundamental: P/E ratio, EPS growth, Revenue growth
   - Sentiment: News sentiment, Social media mentions
5. Backtest equity curve generation:
   - Start with $100,000
   - Apply realistic daily returns (-5% to +5%)
   - Ensure final equity matches total return
6. Create seed script in `src/lib/mock-data/seed-research.ts`
