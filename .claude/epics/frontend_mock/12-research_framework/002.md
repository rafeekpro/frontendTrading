# Task: Research dashboard page

## Description
Build the main research dashboard page with hypotheses list, status filtering, and quick access to backtest results. Display hypothesis cards with key metrics including status, last tested date, win rate, and profit factor. This is the landing page for systematic research and hypothesis management.

## ⚠️ TDD Requirements
**This project uses Test-Driven Development. You MUST:**
1. 🔴 RED: Write failing test first
2. 🟢 GREEN: Write minimal code to make test pass
3. 🔵 REFACTOR: Clean up code while keeping tests green

See `.claude/rules/tdd.enforcement.md` for complete requirements.

## Acceptance Criteria
- [ ] ResearchDashboardPage component at `/src/pages/Research/ResearchDashboardPage.tsx`
- [ ] Hypotheses list with grid/list view toggle
- [ ] HypothesisCard component with key metrics
- [ ] Filter by status: All, Draft, Testing, Validated, Rejected
- [ ] Sort options: Newest first, Best performance, Most traded
- [ ] Quick stats cards: Total hypotheses, Validated count, Avg win rate, Avg profit factor
- [ ] "Create New Hypothesis" button (opens mock form)
